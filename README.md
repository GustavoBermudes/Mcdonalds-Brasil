# McDonald's Brasil - Site Oficial

## 1. Nome do site, aplicativo ou sistema
**McDonald's Brasil (Site Oficial)**

## 2. Descrição
O McDonald's Brasil é o portal oficial da rede McDonald's no país. Ele permite que os clientes consultem o cardápio, conheçam lançamentos, localizem restaurantes, acessem promoções e utilizem serviços de pedidos online, como retirada no restaurante e entrega via McDelivery.

O site deve ser utilizado por clientes que desejam conhecer os produtos da marca, realizar pedidos, obter informações institucionais ou encontrar restaurantes próximos.

## 3. Público-alvo
- Clientes do McDonald's
- Jovens, adultos e famílias
- Pessoas interessadas em promoções e lançamentos
- Usuários que desejam realizar pedidos online
- Interessados em oportunidades de trabalho e franquias

## 4. Funcionalidades
- Visualização do cardápio completo
- Consulta de lançamentos e promoções
- Localização de restaurantes
- Realização de pedidos online
- Acesso ao McDelivery
- Consulta de formas de pagamento
- Cadastro e login de usuários
- Atendimento e suporte ao cliente
- Informações institucionais da empresa
- Área de franquias
- Área de carreiras e vagas de emprego
- Informações sobre sustentabilidade e responsabilidade social

## 5. Tecnologias Utilizadas
As tecnologias abaixo foram identificadas no site utilizando a extensão **Wappalyzer**.

### Front-end
- **Vue.js** — framework JavaScript utilizado na construção da interface
- **Nuxt.js** — framework baseado em Vue.js, utilizado para desenvolvimento de aplicações web
- **Tailwind CSS** — framework CSS utilitário para estilização da interface
- **PrimeVue** — biblioteca/framework de componentes de interface para Vue.js

### JavaScript e gerenciamento de estado
- **Pinia** — biblioteca oficial de gerenciamento de estado para aplicações Vue.js
- **Swiper** — biblioteca JavaScript utilizada para sliders, carrosséis e componentes interativos

### Geração e estrutura do site
- **Nuxt.js** — também identificado como gerador de sites estáticos

### Analytics e monitoramento
- **Datadog** — utilizado para analytics, monitoramento de desempenho e RUM (Real User Monitoring)
- **Google Tag Manager** — gerenciamento de tags, métricas e scripts de rastreamento

### CDN e infraestrutura
- **Cloudflare** — CDN e serviços de infraestrutura, desempenho e segurança

### Metadados e compartilhamento
- **Open Graph** — protocolo utilizado para definir metadados de páginas e melhorar o compartilhamento em redes sociais

> **Observação:** as tecnologias foram detectadas por ferramentas de análise de tecnologias web e podem não representar toda a infraestrutura interna ou o back-end utilizado pelo McDonald's.

## 6. Requisitos Técnicos para Utilização
- Computador, notebook, tablet ou smartphone
- Navegador atualizado (Google Chrome, Microsoft Edge, Firefox ou Safari)
- Conexão com a internet
- Conta cadastrada para acesso a benefícios e promoções exclusivas
